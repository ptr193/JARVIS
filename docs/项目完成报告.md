## 六、明确未完成与验证边界

1. 当前 VM 是 PRoot 用户态环境，不是 Hypervisor/QEMU；真机 PRoot、VNC、su 与长运行会话未验收。
2. 默认模型及导入模型的真实下载、加载、推理性能与内存占用未在真机验收。
3. 电话、短信、麦克风、传感器、蓝牙、PPG、摄像头、生物识别和厂商 ROM 行为未验收。
4. 云服务未配置，云同步、远程医疗、智能家居和双设备流程保持 `NOT_RUN/BLOCKED`。
5. Fake、Mock、JDBC、JVM 本地端点与源码契约测试只验证对应生产逻辑，**不冒充**真实硬件、推理、PRoot/VNC/su 或云服务验收。
6. Release 仍被需求缺口和外部验收阻断；本次未构建、未交付 Release。
