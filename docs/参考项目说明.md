# JARVIS 项目参考说明

## 参考项目

### 1. Kai 9000（UI 和结构参考）

**项目地址**: https://github.com/SimonSchubert/Kai

**参考内容**:

#### UI 设计
- 简洁的卡片式消息气泡
- 底部导航栏设计
- 清晰的用户/AI 消息区分
- 现代化的 Material Design 风格

#### 项目结构
- 模块化设计（inference、data、ui、tools、mcp、skills 等）
- Repository 模式封装数据访问
- MVI/MVVM 架构模式
- 依赖注入（Koin）

#### 核心功能实现方式
- 对话引擎：MVI + Agent Loop 模式
- 模型调度：多服务 Fallback 架构
- 工具系统：可扩展的工具执行框架
- 记忆系统：跨对话持久化记忆

### 2. Haven（虚拟机参考）

**项目地址**: https://github.com/GlassOnTin/Haven

**参考内容**:

#### 虚拟机实现
- 基于 PRoot 的用户态 chroot（无需 root 权限）
- 多发行版支持（Alpine、Debian、Arch、Void）
- 每个发行版独立的 rootfs

#### PRoot 集成
- 下载和管理 PRoot 二进制文件
- rootfs 下载和解压
- 文件系统绑定（/dev、/proc、/sys 等）
- 环境变量配置

#### 桌面环境
- Wayland 合成器（labwc/wlroots）
- GPU 加速显示
- VNC/RDP 远程桌面

#### 文件管理
- 统一文件浏览器
- 跨文件系统操作
- rclone 云存储集成

#### 软件包管理
- 各发行版原生包管理器（apk、apt、pacman、xbps）
- 在 PRoot 环境内执行包管理命令

#### 终端实现
- SSH + Mosh + Eternal Terminal
- tmux 感知会话恢复
- 可配置键盘工具栏

| 对话引擎 | MVI + Agent Loop | - | ChatEngine + ModelCapabilityScheduler |

## 虚拟机类型说明

### 传统虚拟机（终端式）
- 基于 proot 的轻量级 Linux 环境
- 终端命令行操作
- 适合开发和系统管理
- 低功耗，启动快速

### Haven 风格虚拟机（桌面式）
- 基于 PRoot + Wayland 的完整桌面体验
- GPU 加速显示
- 支持 GUI 应用
- 多窗口管理
- 远程桌面访问
