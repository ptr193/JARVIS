## 3. 问题清单与修复记录

### 3.1 已发现并修复的 Bug

#### Bug #1：VmManager ID 冲突（严重）

- **现象**：`VmManagerTest > multiple vms run independently` 失败
  - `expected:<STOPPED> but was:<RUNNING>`
- **根因**：`create()` 使用 `System.currentTimeMillis()` 作为 ID。两个虚拟机在同一毫秒内创建时，会得到相同 ID；随后 `start(a.id)` 会同时启动 a 和 b。
- **影响**：多虚拟机管理场景下，启动一个虚拟机会意外启动同毫秒创建的其他虚拟机。
- **修复**：[VmManager.kt](file:///workspace/app/src/main/java/com/jarvis/pineapple/vm/VmManager.kt) 引入计数器，ID 格式改为 `vm_${时间戳}_${计数器}`，保证唯一性。

### 3.2 Lint 错误修复（共 33 处 → 0 处）

#### MissingPermission（3 处 → 0 处）

- [PhoneController.kt](file:///workspace/app/src/main/java/com/jarvis/pineapple/system/PhoneController.kt)：`call()` / `answerCall()` / `readCallLogs()` 添加 `@SuppressLint("MissingPermission")`，并标注运行时权限由调用方确保。
- [SystemSettingsController.kt](file:///workspace/app/src/main/java/com/jarvis/pineapple/system/SystemSettingsController.kt)：`setWifiEnabled()` / `setBluetoothEnabled()` 添加 `@SuppressLint`。
- [VoiceWakeDetector.kt](file:///workspace/app/src/main/java/com/jarvis/pineapple/wake/VoiceWakeDetector.kt)：`start()` 添加 `@SuppressLint`，并补全异常说明。

#### NewApi（API 24+ 调用，minSdk 23）（多处 → 0 处）

- [AutonomousModules.kt](file:///workspace/app/src/main/java/com/jarvis/pineapple/autonomous/AutonomousModules.kt)：`java.util.PriorityQueue`（API 24）替换为 `mutableListOf` + `sortByDescending`，兼容 API 23。
- [CrossAppOperator.kt](file:///workspace/app/src/main/java/com/jarvis/pineapple/system/CrossAppOperator.kt)：`swipe()` 添加 `@RequiresApi(N)`，因 `GestureDescription` 仅在 API 24+ 可用。
- [JarvisAccessibilityService.kt](file:///workspace/app/src/main/java/com/jarvis/pineapple/accessibility/JarvisAccessibilityService.kt)：`performClick()` 添加 `@RequiresApi(N)`。
- [JarvisTileService.kt](file:///workspace/app/src/main/java/com/jarvis/pineapple/service/JarvisTileService.kt)：类级 `@RequiresApi(N)`，并在 [AndroidManifest.xml](file:///workspace/app/src/main/AndroidManifest.xml) 添加 `tools:targetApi="24"`。
- [SecurityModules.kt](file:///workspace/app/src/main/java/com/jarvis/pineapple/security/SecurityModules.kt)：`BiometricAuth.authenticate()` 添加 `@RequiresApi(P)`，因 `Context.getMainExecutor` 仅在 API 28+ 可用。

#### UnspecifiedRegisterReceiverFlag（1 处 → 0 处）

#### StartActivityAndCollapseDeprecated（1 处 → 0 处）

- [JarvisTileService.kt](file:///workspace/app/src/main/java/com/jarvis/pineapple/service/JarvisTileService.kt)：根据系统版本分支，Android 14+ 改用 `PendingIntent` 变体，旧版本用 `@SuppressLint` 抑制。

#### PermissionImpliesUnsupportedChromeOsHardware（3 处 → 0 处）
