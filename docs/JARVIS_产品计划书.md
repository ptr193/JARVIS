# JARVIS 产品计划书

> 本文档详细规划 JARVIS 项目的开发流程，明确每个分区和任务的目标、交付物与验收标准。
> 版本：0.0.1 | 包名：com.jarvis.pineapple | 最低 Android 6

---

## 总则

### 开发流程

```
分区 N → 小任务 1..n → 编码 → 运行测试（不打包） → 修复 → 测试通过
    ↓
汇报进度 + 交付物 → 用户确认 → 进入分区 N+1
    ↓
所有分区完成 → 全量运行测试 → Debug APK 实机测试 → 修复 → 发行版 APK
```

### 任务定义格式

每个小任务必须明确：
- **做什么**：任务名称与范围
- **实现什么**：具体功能点
- **交付什么**：可验证的产物（代码文件 / 界面 / 可运行功能）
- **验收标准**：如何判断完成

### 汇报机制

- 每完成一个分区，向用户汇报进度百分比
- 交付物必须可验证
- UI 相关任务必须提供界面预览，用户确认后再继续

## 分区 1：项目骨架 + 人格系统 + 主界面框架

**目标**：建立项目基础结构，实现 JARVIS 人格系统，搭建主界面框架。

### 任务 1.1：项目初始化

- **做什么**：创建 Android 项目骨架
- **实现什么**：
  - Gradle 项目结构（Kotlin DSL）
  - 包名 `com.jarvis.pineapple`
  - minSdk 23 / targetSdk 37
  - 版本 0.0.1
  - Jetpack Compose + Material 3
  - Koin 依赖注入
  - SQLDelight 数据库
  - Ktor 网络
- **交付什么**：可编译运行的空项目
- **验收标准**：项目能在模拟器中启动并显示空白主界面

### 任务 1.2：人格系统（灵魂）

- **做什么**：实现 JARVIS 人格 system prompt 管理
- **实现什么**：
  - 人格描述数据结构（基于《JARVIS 人格灵魂描述》文档）
  - 人格配置持久化
  - 人格 prompt 动态生成
  - 支持用户自定义修改人格描述
- **交付什么**：人格系统模块 + 人格编辑界面
- **验收标准**：能加载默认 JARVIS 人格，对话时 AI 表现符合人格设定；用户可在设置中修改人格

### 任务 1.3：主界面框架

- **做什么**：搭建主界面布局
- **实现什么**：
  - 顶部：左侧"虚拟机"入口、中间声音播放按钮、右侧"设置"入口
  - 中部：对话消息列表区域
  - 底部：模型选择按钮（默认本地模型）、上传文件/图片、输入框、发送按钮
  - 消息气泡 UI（用户消息 / AI 消息）
- **交付什么**：主界面可交互原型
- **验收标准**：界面元素齐全，布局正确，可输入文本并显示在对话区

### 分区 1 验收

- 项目可编译运行
- 默认人格为 JARVIS
- 主界面三区域布局完整
- 进度：8%

## 分区 2：模型管理层 + 对话引擎

**目标**：实现模型选择与调度，完成基础对话功能。

### 任务 2.1：模型抽象层

- **做什么**：定义统一的模型接口
- **实现什么**：
  - Model 接口（load / generate / stream / unload）
  - 模型状态管理（未加载 / 加载中 / 就绪 / 错误）
  - 模型优先级调度（用户模型 > 5 个 LiteRT > API 模型 > 服务器模型）
- **交付什么**：模型接口定义 + 调度器
- **验收标准**：接口可扩展，能按优先级选择模型

### 任务 2.2：本地模型管理

- **做什么**：实现 6 个本地模型的管理
- **实现什么**：
  - 用户自有模型（默认，最高优先级）
  - 5 个 LiteRT 模型（Gemma 4 E2B 2.5B、Gemma 4 12B、LFM2.5 1.7B、Qwen3 0.6B 等）
  - 模型列表展示与选择
  - 模型加载/卸载
- **交付什么**：模型选择界面 + 加载逻辑
- **验收标准**：用户可在 6 个模型中选择，选择后能加载并用于对话

### 任务 2.3：API 模型接入

- **做什么**：实现云端 AI API 接入
- **实现什么**：
  - 多服务商 API 适配（OpenAI 兼容协议为主）
  - API Key 加密存储
  - 用户配置 API 后可调用对应模型
- **交付什么**：API 配置界面 + 调用逻辑
- **验收标准**：用户输入 API Key 后可选择并调用对应云端模型

### 任务 2.4：服务器模型连接

- **做什么**：实现个人服务器 AI 模型连接
- **实现什么**：
  - 服务器地址配置
  - 连接状态管理
  - 模型调用
- **交付什么**：服务器配置界面 + 连接逻辑
- **验收标准**：用户配置服务器地址后可连接并调用服务器上的模型

### 任务 2.5：对话引擎

- **做什么**：实现对话核心逻辑
- **实现什么**：
  - 多轮对话上下文管理
  - 消息发送与接收
  - 流式回复
  - 对话历史持久化
  - 人格 prompt 注入
- **交付什么**：完整的对话功能
- **验收标准**：用户可与 AI 进行多轮对话，AI 回复符合 JARVIS 人格

### 分区 2 验收

- 6 个本地模型可选择并加载
- API 模型可配置并调用
- 服务器模型可连接
- 多轮对话正常，人格一致
- 进度：15%
